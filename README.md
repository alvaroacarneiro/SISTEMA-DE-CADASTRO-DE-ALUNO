# 📚 Sistema de Cadastro de Alunos

[![Java](https://img.shields.io/badge/Java-17%2B-orange?logo=java)](https://www.oracle.com/java/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Sistema de gerenciamento acadêmico desenvolvido em **Java 17** para cadastro, consulta e persistência de alunos. Ideal para portfólio e estudos de **Orientação a Objetos** e **Manipulação de Arquivos**.

## ✨ Funcionalidades

- ➕ **Adicionar aluno** (com validação de matrícula duplicada).
- 📋 **Listar todos os alunos** com status de aprovação (média >= 7.0).
- 🔍 **Buscar aluno** por matrícula.
- 🗑️ **Remover aluno** por matrícula.
- 📊 **Calcular média geral** da turma.
- 💾 **Persistência automática** em arquivo CSV (os dados são salvos mesmo após fechar o programa).

## 🛠️ Tecnologias Utilizadas

- **Java 17** (LTS)
- **Java I/O** (`BufferedReader`, `FileWriter`) para manipulação de arquivos
- **Coleções** (`ArrayList`) para gerenciamento em memória
- **Programação Orientada a Objetos** (Encapsulamento, Classes, Métodos)
